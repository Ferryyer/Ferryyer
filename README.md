# Ferryyer

## GPU 任务台 · macOS 桌面小组件

在桌面查看自己的 GPU 任务概况；打开网页可查看队列和步骤进度、调整顺序、开始或停止任务。

**[⬇ 下载 macOS 桌面小组件（ZIP）](https://raw.githubusercontent.com/Ferryyer/Ferryyer/main/downloads/GPU-Queue-Widget-1.1.0-macOS.zip)**

1. 在 Mac 上下载并解压整个文件夹，双击 **安装桌面小组件.command**。
2. 按提示选择已有的个人 SSH 配置；需要登录时，点击面板的“完成登录”。
3. 安装后会创建桌面入口，之后每次登录 Mac 都会自动打开并尝试连接服务器。

已安装小组件，只想开启自启动：双击新版包中的 **开启开机自启动.command**。关闭自启动则双击 **关闭开机自启动.command**。

小组件用于连接本人的服务器，需要已有的 SSH 访问权限。任务数据留在服务器；安装包不包含密码、私钥或任务记录。GPU 任务仍需在网页点击“开始”，关闭小组件不会停止已经运行的任务。
